# Signal Join Page

This page helps people join a Signal group when links are opened inside apps like Facebook or Instagram.

Those apps open links inside their own browser, which can stop Signal links from working. This page explains what to do so the link opens correctly.

## What this page does

- Shows a message if the link is opened inside Facebook or Instagram
- Tells the user how to open the link in their normal browser
- Lets them continue once it’s opened properly
